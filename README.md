# StardewValley-indoorCamping

事情是这样的…我上次打骷髅矿洞100层实在是下不去，于是我用ai做了一个可以在矿洞里放置帐篷并过夜的mod。他不改变帐篷的样式，不是可重复利用的（其实就是比较方便懒得改啦），第二天醒来会在矿洞当前层但是矿物和怪物会刷新。

星露谷mod:一个可以在室内（包括矿洞）放置帐篷的mod。Stardew Valley mod: a mod that lets you place tents indoors (including in the mines)

## 下载模组

[下载 Indoor Camping 0.1.1 测试版安装包](downloads/IndoorCamping-0.1.1.zip?raw=true)

让原版帐篷工具包能在普通室内、普通矿井和骷髅洞穴使用。仅支持 PC 单人游戏。

## 0.1.1 修复说明

0.1.0 收到实测反馈：矿洞睡眠后在农舍醒来，且人物无法操作。请更新到 0.1.1。此版把早晨恢复改为等待跨天、存档和淡入完成后再执行，传送成功后才清除记录；传送回调丢失超过 600 个更新帧时，取消本次恢复、回农舍并清理传送与操作锁定。新增自动回归检查覆盖淡入等待、重复早晨事件、传送无回调超时和完成后不再重试。

若更新后仍遇到无法操作，可在 **SMAPI 控制台** 输入 `indoorcamping_recover`，该命令会终止恢复流程并送回农舍、解除锁定。退出游戏后再替换模组文件夹；保留自己的 `config.json`。旧版当天存档若已丢失露营记录，无法凭空恢复原矿层，需要重新进入矿洞验证。

2026-11-11， **0.1.1 实际游戏测试通过**：本次反馈涉及的矿洞过夜与次日无法操作问题已复测通过。

## 安装和使用

1. 使用已安装 SMAPI 的星露谷物语。目前编译基准为本机 **游戏 1.6.15、SMAPI 4.5.2**。
2. 解压 `dist/IndoorCamping-0.1.1.zip`，把里面的 `IndoorCamping` 文件夹放入游戏 `Mods` 目录。
3. 从 SMAPI 启动游戏，携带原版帐篷工具包，在有足够空地的位置放置并交互入睡。

原版物品、配方、外观、占地、消耗和睡眠结算不变。成功放置时按原版消耗一个工具包；取消睡眠不会再扣物品，帐篷仍留在地上。并非取消睡眠后退还已放置的工具包。

普通室内次日在原位置附近醒来；矿洞在同层入口附近醒来。矿层按新一天重新生成，矿石、怪物和梯子不保留。骷髅洞穴使用原游戏层数编码（例如显示第 1 层对应内部第 121 层）。矿洞入口有与原版进入矿洞相同长度的短暂无敌保护。

火山地牢、采石场矿洞、临时事件地图、节庆场景不支持。节日前夜的原版帐篷限制仍然有效。不会解除开门时间、NPC 作息或其他地图规则。退出游戏后重新加载当天早上的存档，仍会尝试恢复露营地点。

## 配置

关闭游戏后编辑模组文件夹里的 `config.json`，三个选项默认均为 `true`：

| 选项 | 作用 |
| --- | --- |
| `EnableIndoorLocations` | 普通、持久存在的室内地图 |
| `EnableMines` | 普通矿井 1–120 层 |
| `EnableSkullCavern` | 骷髅洞穴 |

设置为 `false` 后，该类地点不再允许放置或使用帐篷。读档恢复时若地点已关闭、消失或没有安全落点，会回到农舍并显示提示。联机时室内扩展关闭，原版户外帐篷照常运行。

## 构建

本机无 .NET SDK，`build.ps1` 使用已安装的 Visual Studio Roslyn 编译器，以及游戏自带的 .NET 6 和 SMAPI 程序集，不下载或打包游戏文件。

```powershell
.\build.ps1
.\tests\run.ps1
# 自定义位置：
.\build.ps1 -GamePath 'D:\Games\Stardew Valley' -CompilerPath 'C:\path\to\Roslyn\csc.exe'
```

输出为 `dist/IndoorCamping/` 和 `dist/IndoorCamping-0.1.1.zip`。也提供 `IndoorCamping/IndoorCamping.csproj`，有 .NET SDK 时可使用 `dotnet build -p:GamePath="游戏目录"` 编译源码；完整安装包由 `build.ps1` 生成。测试脚本需要 .NET 7 或更新运行时，只加载方法和应用补丁，不启动游戏、不读取玩家存档。

## 保存与兼容

露营记录写在玩家 `modData` 的 `Zhang.IndoorCamping/Wake` 键中，随原版存档一起保存，包含地点、矿层、坐标和次日日期。仅在确认帐篷睡眠且开始跨天后创建。原版先完成跨天结算及存档，再恢复露营位置。记录按日期生效，内存中同一天只恢复一次；硬盘上的早晨存档保留记录，以便退出后重载。下一次正常存档会替换或移除旧记录。

未修改原版地图的室内／室外标志，也不引入自定义游戏实体。移除模组后失去室内露营与矿层恢复能力；建议早晨回农舍并再睡一晚保存后卸载。修改帐篷、睡眠或传送的其他模组可能冲突，扩展地图尚未验证。
