# StardewValley-indoorCamping

事情是这样的…我上次打骷髅矿洞100层实在是下不去，于是我用ai做了一个可以在矿洞里放置帐篷并过夜的mod。如果你喜欢原汁原味的星露谷，同时又想享受mod带来的便利性，那么这款mod或许适合你——他不改变帐篷的样式，不是可重复利用的（其实就是比较方便懒得改啦），第二天醒来会在矿洞当前层但是矿物和怪物会刷新。

星露谷mod:一个可以在室内（包括矿洞）放置帐篷的mod。Stardew Valley mod: a mod that lets you place tents indoors (including in the mines)
